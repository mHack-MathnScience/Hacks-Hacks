# Hack’s Hacks

Grade 5 classroom hub: **Math Hacks** (generated Texas TEKS practice) and **Science Hacks** (labs, notebook, Check-it quiz).

Progress is saved on the device (no student accounts).

## What’s inside

**Math Hacks** — randomly generated stations listed by [Grade 5 mathematics TEKS](https://tea.texas.gov/about-tea/laws-and-rules/texas-administrative-code/19-tac-chapter-111) (19 TAC §111.7). Place-value items that name a digit use a number where that digit appears only once.

**Science Hacks** — 16 labs (forces, landforms, circuits, rocks), a CER notebook, a 21-item Check-it quiz, teacher lesson paths, and STAAR-style review. Science TEKS follow the 2024 Grade 5 science standards (19 TAC §112.16).

## Live classroom site

Share a published `grok.me` link, or import this repo into [Netlify](https://app.netlify.com) (sign up with GitHub → **Add new site** → **Import from Git** → `Hacks-Hacks`). Students get a `something.netlify.app` address. Visitors can practice; they cannot edit the project.
